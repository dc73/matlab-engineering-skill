# Glossary — MATLAB: An Introduction with Applications (6th ed.)

Alphabetical index of the book's key terms. Chapter references (Ch N) point to the chapter that introduces each term.

**`A\b` (left division)** — solves linear systems `A*x = b`; preferred over explicit `inv(A)*b`. (Ch 3)
**`arguments` block** — typed, validated function interface (release-dependent). (Ch 7)
**`anonymous function`** — `@(x) expr` inline function handle for solver APIs. (Ch 7.8)
**`assert`** — test assertion; used with tolerance-based checks. (repo SKILL.md, Ch 9)
**`axis`** — set axis limits/format for plots. (Ch 5)
**`bwareaopen` / `bwconncomp`** — image processing (separate toolbox, not this book).
**`cd`** — change the current folder (script location). (Ch 1.8.4, Ch 4)
**`clc`** — clear the Command Window. (Ch 1.2)
**`clear` / `clear all`** — remove variables / wipe the whole session. (Ch 1.7, Ch 4.1)
**`colon` (`:`)** — evenly spaced vector generation: `a:b` (step 1) or `a:step:c`. (Ch 2.1)
**`compass`** — compass plot (vector field on a circle). (Ch 5)
**`contour` / `contour3d`** — 2-D contour lines / 3-D contour surfaces. (Ch 10)
**`conv`** — convolution (Signal Processing Toolbox, separate).
**`cosd` / `sind` / `tand`** — degree-based trig; use only for degree inputs (radian-based `sin`, `cos`, `tan` are the default). (Ch 1.5, repo SKILL.md)
**`csvread` / `dlmread` / `importdata`** — import tabular/delimited data into the workspace. (Ch 4.5)
**`current folder`** — directory MATLAB uses to find scripts; change with `cd` or the toolbar. (Ch 1.8.4)
**`diff` (symbolic)** — symbolic derivative. (Ch 11)
**`disp` / `fprintf`** — output commands: `disp` prints with the current display format; `fprintf` uses explicit format specifiers. (Ch 4.3)
**`dsolve`** — symbolic ODE solver with initial conditions. (Ch 11)
**`eye(n)`** — n×n identity matrix; also `eye(m,n)` rectangular. (Ch 2.2.1)
**`ezplot`** — legacy symbolic plotting. (Ch 11.7)
**`fminbnd` / `fminunc`** — bounded / unbounded 1-D minimization; for maxima, minimize the negative. (Ch 9.2)
**`fplot`** — plot a function (string or handle) over an interval; used to locate `fzero` brackets. (Ch 9.1)
**`fzero`** — find a zero where the function crosses the x-axis; accepts string, handle, or anonymous function; `[x, fval]` gives the residual. (Ch 9.1)
**`grid on`** — add grid lines to a plot. (Ch 5)
**`hold on`** — overlay additional curves in the same axes. (Ch 5)
**`if` / `elseif` / `else`** — conditional flow control. (Ch 6.2)
**`int` (symbolic)** — symbolic integral, indefinite by default; specify limits for definite. (Ch 11)
**`integral`** — numerical 1-D integration with an error bound (modern `integral`; legacy `quad`/`quadg`/`quadl`). (Ch 9)
**`interp1` / `interpn`** — interpolation between data points; methods `'linear'` (default), `'pchip'`, `'spline'`, `'nearest'`. (Ch 8.3)
**`inv`** — explicit matrix inverse; avoid in favor of `A\b`. (Ch 3)
**`isinf` / `isnan`** — detect Inf/NaN; handle deliberately, don't filter silently. (repo SKILL.md, Ch 3)
**`legend`** — label overlaid curves. (Ch 5)
**`linspace(a, b, n)`** — n evenly spaced points between endpoints a and b; the go-to for axis vectors. (Ch 2.1)
**`load` / `save`** — restore / write workspace variables to `.mat` files; use versioned filenames. (Ch 4.4)
**`loglog` / `semilogx` / `semilogy`** — log-scale axes for wide-range data. (Ch 5)
**`mesh` / `surf`** — 3-D wireframe / shaded surface plots. (Ch 10)
**`meshgrid(x, y)`** — build the X (rows of x) and Y (columns of y) matrices for surface grids. (Ch 10.2)
**`ode45`** — explicit Runge-Kutta (4,5) for non-stiff first-order ODEs; `[t, Y]` output with Y rows = states over time. (Ch 9)
**`ones(m,n)` / `zeros(m,n)`** — preallocation tools; never grow arrays in loops. (Ch 2.2.1)
**`optimset('display','iter')`** — show `fzero`/`fminbnd` iteration output. (Ch 9)
**`polyder` / `polyint` / `polyfit` / `polyval` / `roots`** — polynomial toolkit: derivative, integral, least-squares fit, evaluation, root finding. Coefficient vector = highest power first, zeros included. (Ch 8)
**`plot` / `plot3`** — 2-D / 3-D line plots with line/color/marker specifiers. (Ch 5, Ch 10)
**`persistent`** — variable that survives function calls; use sparingly, document it. (Ch 7)
**`quadv` / `quadg` / `quadl`** — legacy numerical integration (adaptive). (Ch 9)
**`rand` / `randn` / `randi`** — random number generators; use deterministic seeds for reproducible tests. (Ch 3.7, repo SKILL.md)
**`solve`** — symbolic equation solver. (Ch 11)
**`syms` / `sym`** — create symbolic variables / objects. (Ch 11.1)
**`switch` / `case`** — multi-way discrete branching. (Ch 6.3)
**`title` / `xlabel` / `ylabel` / `zlabel`** — plot labels. (Ch 5)
**`type`** — print a text file to the Command Window. (Ch 4)
**`view(az, el)` / `cam`** — aim the 3-D camera (azimuth/elevation/distance). (Ch 10)
**`who` / `whos`** — list workspace variables (name / +class, size, bytes). (Ch 1.7, Ch 4.1)
**`xor`** — logical XOR (element-wise). (Ch 6.1)
**`zeros`** — zero matrix; the standard preallocation primitive. (Ch 2.2.1)
